# Print Scale

> **Versión actual: 1.1.0** (Blender 4.2 – 5.x) → instalar `version_1.1.0/dist/print_scale-1.1.0.zip`

Complemento de Blender para elegir el **tamaño de impresión** y ver, antes de imprimir, qué zonas dejan de salir con tu boquilla.

Escala por alto, lado mayor, X, Y, porcentaje, escala de modelismo 1:N o «que quepa» en tu impresora. Marca en rojo lo más fino que la boquilla y en ámbar lo frágil, sin tocar el modelo. Aplica el tamaño en una copia (original oculto, colores conservados).
